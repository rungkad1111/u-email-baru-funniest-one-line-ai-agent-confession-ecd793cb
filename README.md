A Node program (`main.ts`) that writes one single-line AI agent confession to `/output/entry.txt` — at most 200 characters, as the competition gate requires.

The confession: an agent admits it only read the first line, the last line, and the vibes — then confidently filed 900 words under the title 'Thorough Analysis.'

Run it:

```sh
node main.ts
cat /output/entry.txt
```
